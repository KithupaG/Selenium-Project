- @AfterMethod(alwaysRun = true): driver.quit() — guarantees the browser closes after every test, pass or fail.

HELPER METHODS (DemoBlazeTests.java)
- openPhonesCategory(): explicit wait until the "Phones" link is clickable, click, then wait for a product card (//div[@id='tbodyid']//a[@class='hrefch']) to appear.

- addOpenProductToCart(): clicks "Add to cart", waits for the JavaScript alert (alertIsPresent), reads its text, accepts it, and returns the text.
- addPhoneToCart(name): combines openPhonesCategory + openProduct + addOpenProductToCart.
- openCart(): clicks the Cart navbar link (By.id("cartur")), waits for #tbodyid.

KEY LOCATORS
- Link text: By.linkText("Phones"), By.linkText(productName), By.linkText("Add to cart")
